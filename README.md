# LeadLine Productions Website

A modern, luxury-focused website for LeadLine Productions, a premier event management company specializing in corporate events, weddings, political conferences, concerts, trade shows, and social galas.

**Tagline:** Your Ask Is Our Task

## Website Structure

The website consists of the following sections:
- Home/Hero
- About Us
- Services
  - Corporate Events & Conferences
  - Wedding Planning & Design
  - Political Events & Government Affairs
  - Concert & Festival Production
  - Trade Shows & Exhibitions
  - Social Galas & Celebrations
- Testimonials
- Careers
- Contact

## Technologies Used

- HTML5
- CSS3 (with custom properties and modern layouts)
- JavaScript (vanilla)
- Font Awesome (for icons)
- Google Fonts (Playfair Display and Montserrat)

## Image Requirements

For optimal display, please place appropriate images in the `/images` folder:

- `hero-image.jpg` - Main hero background (1920x1080px) - Beautiful event setup or celebration scene
- `about-image.jpg` - About section image (800x600px) - Event planning team in action
- `corporate-events.jpg` - Corporate Events service image (600x400px)
- `wedding-planning.jpg` - Wedding Planning service image (600x400px)
- `political-events.jpg` - Political Events service image (600x400px)
- `concert-production.jpg` - Concert Production service image (600x400px)
- `trade-shows.jpg` - Trade Shows service image (600x400px)
- `social-galas.jpg` - Social Galas service image (600x400px)
- `careers-image.jpg` - Careers section image (800x600px)

Recommended image themes for each service:
- Corporate Events: Conference setup, product launch, or corporate gala
- Wedding Planning: Elegant wedding ceremony or reception
- Political Events: Political conference, diplomatic reception, or government meeting
- Concert Production: Music festival, concert stage, or live performance
- Trade Shows: Exhibition booth, trade show floor, or product showcase
- Social Galas: Charity gala, fundraising dinner, or award ceremony

## Video Requirements

For the hero background video:
- Place a video file named `security-bg.mp4` in the `/videos` folder (or rename to `event-bg.mp4`)
- Recommended: 15-30 second loop of beautiful event setups, celebrations, or event planning scenes
- Format: MP4, 1080p or higher
- If no video is provided, the site will fall back to the hero image

## Color Scheme

The website uses a luxury dark theme with dark orange accents:
- Dark backgrounds: #0a0a0c and #050507
- Light text: #f5f5f7
- Dark Orange accents: #ff6b35 (primary), #ff8c5a (light)
- Navy accents: #1a2b47

## Browser Compatibility

The website is optimized for:
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Mobile Responsiveness

The website is fully responsive with optimized layouts for:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (320px - 767px)

## Maintenance

To update content, edit the corresponding sections in the HTML file. The site structure is modular, making it easy to add new sections or modify existing ones.
